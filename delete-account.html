CHROMA FRACTURE

Suppression du compte et des données

Dernière mise à jour : 22 novembre 2026

Un compte joueur existe-t-il ?

Chroma Fracture ne propose actuellement ni création de compte joueur ni connexion à un compte. Il n’existe donc pas de compte Chroma Fracture à fermer sur un serveur de l’éditeur. Cette page explique comment effacer les données du jeu et demander la suppression d’informations éventuellement traitées pour les diagnostics ou l’assistance.

1. Effacer les données sur le téléphone

  1. Ouvrez les Paramètres du téléphone Android.
  2. Allez dans Applications → Chroma Fracture → Stockage.
  3. Choisissez Effacer les données ou Effacer le stockage, selon le téléphone.

Cette opération supprime les réglages et les éventuels scores ou sauvegardes conservés dans l’espace local de l’application. Elle réinitialise le jeu. La désinstallation supprime normalement aussi ces données locales.

Une sauvegarde automatique Android peut restaurer des données lors d’une réinstallation. Si vous souhaitez également supprimer une sauvegarde du système, gérez-la dans les paramètres de sauvegarde Android ou de votre fournisseur de sauvegarde. L’éditeur n’a pas accès à ces sauvegardes.

2. Demander la suppression de données de diagnostic ou d’assistance

Vous pouvez contacter Développement-Solution — Olivier Pagé pour une demande concernant des rapports techniques Unity déjà transmis ou des courriels d’assistance :

Demander la suppression par e-mail

Adresse : developpement.solution@gmail.com.

Indiquez le nom Chroma Fracture, les données concernées et les éléments utiles pour retrouver votre demande, par exemple la date d’un échange d’assistance ou la version du jeu et la période d’un incident. N’envoyez ni mot de passe, ni coordonnées bancaires, ni pièce d’identité sans nécessité.

Nous vous indiquerons les informations nécessaires à l’identification des données et traiterons la demande avec le prestataire concerné lorsque cela est nécessaire. Si les informations disponibles ne permettent pas de retrouver certains rapports, nous vous l’indiquerons. L’envoi d’une demande n’entraîne pas une suppression automatique par cette page.

3. Données conservées et limites

Effacer le stockage local n’efface pas automatiquement les rapports déjà transmis au prestataire de diagnostic ni les courriels d’assistance. Unity annonce une conservation des données personnelles de diagnostic de 90 jours par défaut ; une demande concernant ces données peut nous être adressée par le moyen ci-dessus.

Les messages nécessaires au traitement de votre demande de suppression sont utilisés pour vous répondre et gérer ses suites. Certaines informations peuvent être conservées lorsqu’une obligation légale ou la défense d’un droit le justifie. Les traitements et les destinataires sont détaillés dans la politique de confidentialité.

Cette démarche concerne Chroma Fracture. Elle ne supprime pas votre compte Google, GitHub ou vos données dans d’autres applications.
